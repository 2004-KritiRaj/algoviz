# AlgoViz 🔬

A React-based algorithm visualizer for sorting and graph traversal algorithms.

🚧 Currently in development.

## Planned Features
- Bubble Sort, Merge Sort, Quick Sort, BFS, DFS visualizations
- Step-by-step animation with speed control
- Quiz mode to test algorithm knowledge
- Time & space complexity info panel

## Tech Stack
- React 18 + Vite
- Tailwind CSS

## Run Locally
npm install
npm run dev
